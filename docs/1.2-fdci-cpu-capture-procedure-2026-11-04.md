## Validación reproducible y dictamen

Para cada petición esperada exigir exactamente una invocación identificada,
del Worker/versión correctos, ruta y tiempo coherentes, CPU finita no negativa,
HTTP y outcome comprobados. Exportaciones limitadas deben completarse o quedar
rechazadas; no rellenar huecos con eventos ajenos. Duplicados contradictorios,
truncamiento, muestreo incompleto o campos ausentes significan **NO APTO**.

CPU individual **>7 ms**, `exceededCpu`, HTTP **1102** o fallos D1/autorización/
propietario implican suspensión. CPU <=7 en todas las invocaciones completas es
una condición de aprobación de ese ensayo, no una garantía de capacidad futura.
No usar CPU local, wall time o percentiles como alternativa.

**Dictamen actual: NO APTO** para declarar validación individual o permitir
repeticiones automáticas: los registros no son accesibles. El procedimiento de
captura está preparado localmente; un piloto futuro solo será autorizable cuando
se haya demostrado captura y acceso a CPU individual en el canary aislado.
