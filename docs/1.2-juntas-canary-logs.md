## Exportación manual mínima

1. Cloudflare → **Workers & Pages** → `docentetuc-import-canary-1-2` →
   **Observability** → **Invocations**. Fijar el intervalo UTC indicado y
   verificar que el servicio sea exactamente el canary.
2. Mostrar o exportar **JSON** con hora, `requestId`, ruta/trigger, código HTTP,
   `$workers.cpuTimeMs` y `$workers.outcome`. Deben aparecer las 14 invocaciones
   de las rutas anteriores. La vista **Events** también sirve si incluye esos
   campos. No exportar encabezados de autorización, cuerpos ni secretos.
3. Ejecutar localmente, sin credenciales ni acceso a Cloudflare:

   ```powershell
   node scripts/reconcile-juntas-canary-logs.mjs 'C:\ruta\a\la-exportacion.json'
   ```

El lector acepta JSON o JSON Lines, imprime solo campos técnicos y exige
14 invocaciones, conteos por ruta exactos, HTTP 200, `outcome=ok` y CPU
individual ≤7 ms. Si falta un campo o una invocación, deja
`readyForResume=false`. No asociar una métrica agregada a una ruta por
proximidad temporal. El archivo exportado puede contener otros datos: guardarlo
localmente y no subirlo al repositorio ni adjuntarlo completo al chat.

Solo después de conciliar las 14 invocaciones y confirmar el límite se puede
solicitar autorización para **una** reanudación sintética. El checkpoint actual
permanece `PARTIAL`, `page.index=1`, con una publicación y una firma aplicada.
