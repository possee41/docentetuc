## Semántica comprobada

Wrangler instalado 4.92.0 (`node_modules/wrangler/wrangler-dist/cli.js`):

- `versions deploy` llama a `createDeployment` y, después, a `maybePatchSettings`. Este último selecciona los ajustes no versionados definidos, incluida observability, y envía PATCH `/script-settings`. No modifica los bindings de una versión ya creada a partir de `--config`.
- Por tanto, el comando anterior sí puede habilitar observabilidad en esta versión de Wrangler, con el config preparado. No es una propiedad genérica de todo `versions deploy`, ni prueba de que se haya activado: el dry-run termina ANTES de crear el deployment y hacer el PATCH.
- Se retira como operación recomendada: crea un deployment innecesario y sus dos operaciones no son atómicas. Puede crear el deployment y fallar después al modificar los settings. Fijar una versión antigua también añade un riesgo de revertir cambios concurrentes.

- La etiqueta Implementar del Dashboard no demuestra qué endpoints ejecuta. No se da por seguro que un botón conserve el código sin verificar su operación concreta. No se pulsó ni se operó el Dashboard en esta revisión.
