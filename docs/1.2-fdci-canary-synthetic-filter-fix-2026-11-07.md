## Corrección mínima

- Lista fija compartida de **cinco IDs exactos**, sin patrones de títulos, rangos numéricos ni exclusión por trainingId/fuente. Los IDs vecinos y cursos con palabras de prueba siguen admitidos.
- Exclusión SQL antes de los límites/paginación: carga pública Inicio/Capacitaciones, búsqueda textual o por sección, consulta pública por ID, catálogo de coincidencias y selección pública del recuperador IA. No se añadió ninguna consulta ni índice.
- Guardas de presentación en Inicio y Capacitaciones para impedir que la combinación con publicaciones privadas vuelva a introducir esas filas en el catálogo. Guardados, Agenda, notificaciones privadas y sus referencias permanecen intactos.
- Se mantiene `PERSONAL_PUBLICATIONS_QUERY`, la combinación de datos personales y los flags de recordatorios. Si una cuenta ya guardó una de esas filas, conserva su referencia privada; no se borra ni se reescribe.
- Los controles JSON existentes del catálogo usan CASE para manejar metadata NULL, vacía, inválida, null JSON o sin campos. No se desactiva el filtro preview/catalogOnly.
- Lector versionado, catálogo oficial vacío, autenticación, APIs Noticias/Administración, configuración, gateway y automatizaciones no modificados. Los benchmarks antiguos ahora importan el SQL evaluado, evitando interpretar como SQL las interpolaciones del módulo compartido.
