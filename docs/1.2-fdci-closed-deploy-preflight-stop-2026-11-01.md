| ETag de código | Igual | Igual |

El cambio de fecha con igual ETag no prueba un cambio de código ni identifica el ajuste o su autor. Puede corresponder a configuración u otra operación; no se especula sobre la causa. No provino de este ejecutor: hasta ese punto solo se realizaron GET de metadata/código y SELECT de D1, además de comprobaciones HTTP públicas. No se enviaron operaciones de escritura a ningún Worker.

Se registró `OTHER_WORKERS_CHANGED_BEFORE_DEPLOY` y la condición de detención impidió llegar a Wrangler deploy. No se rebasó silenciosamente la línea base para continuar ni se intentó revertir o modificar el canary ajeno.
